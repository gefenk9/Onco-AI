- Use `.venv/bin/mypy` for type checking (mypy installed in virtual environment)
- Use `argparse` for CLI arguments with validation via `choices` parameter
- LLM client is imported from `llm_client.py` using `invoke_llm()` function
- Virtual environment located at `.venv/` - use `.venv/bin/python` for scripts
